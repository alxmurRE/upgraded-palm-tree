# Simple Web Scraper (Python / BeautifulSoup)

Скрипт для автоматического сбора (парсинга) цитат, авторов и тегов с учебного ресурса [Quotes to Scrape](https://toscrape.com). Результат сохраняется в структурированный Excel-файл.

## 🛠 Технологии
* **Python 3**
* **Requests** — отправка HTTP-запросов и кастомизация заголовков (User-Agent).
* **BeautifulSoup4** — парсинг HTML-дерева и извлечение данных по CSS-классам.
* **Pandas / Openpyxl** — обработка данных и экспорт в формат `.xlsx`.

## 🚀 Как запустить проект

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com
   ```
2. Установите зависимости:
   ```bash
   pip install requests beautifulsoup4 pandas openpyxl
   ```
3. Запустите скрипт:
   ```bash
   python scraper.py
   ```

## 📊 Результат работы
После запуска скрипт создает файл `quotes_portfolio.xlsx` в корневой папке проекта со следующей структурой:
* **Цитата** — текст высказывания.
* **Автор** — имя автора.
* **Теги** — тематические теги через запятую.
